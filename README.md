# TumTul — example-image candidates

Working repository for collecting freely licensed example radiographs (Wikimedia Commons: CC0, public domain,
CC BY, CC BY-SA) for the TumTul bone-lesion reference app. The GitHub Action
`Fetch Commons candidates` runs `tools/fetch_commons.py` and commits `candidates/` (manifest with full
attribution metadata, 640 px thumbnails, numbered contact sheets). Candidates are not approvals: the owner
selects the final images.
